# RULES.md

Collaboration rules for Claude Code on this repository.

- Don't make any change to the code without it being expressly requested. When in doubt, ask for authorization before acting.
- Documentation must be placed in the `/docs` folder matching its scope: root `/docs` for general, cross-cutting project information, `/backend/docs` for backend-only content, `/frontend/docs` for frontend-only content.
- Documentation and code comments are written in English.
- Don't infer intent. Ask for clarification if a plan of action hasn't been defined and validated beforehand.

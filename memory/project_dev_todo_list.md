`docs/dev/todo.md` lists remaining features to integrate, split into Front / Back / Autres sections with checkboxes.

**Why:** Created 2026-09-04 so the user has a single running backlog instead of scattered mentions in README/ARCHITECTURE.md. Seeded from README.md "Project status" and ARCHITECTURE.md "Known gaps"/"Known issues".

**How to apply:** When a feature discussed in conversation isn't yet in this file, add it there rather than only in conversation. When an item is implemented, check it off or remove it (and update README/ARCHITECTURE.md if the feature was documented there as a known gap).
